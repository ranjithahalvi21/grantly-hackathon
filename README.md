# GRANTLY — Unified Scholarship Discovery & Management Platform 🚀

> Developed for **THE OUTPOST – Frontend Arena 2026**[cite: 2].

GRANTLY is a modern, responsive web application designed to simplify how students discover, track, and apply for educational financial assistance[cite: 2]. It transforms a historically complex process into a seamless, intuitive digital journey[cite: 2].

## ✨ Core Features
- **Smart Discovery & Search:** Instantly filter and search through active scholarships by keywords or categories (STEM, Merit-Based, Need-Based, Inclusion).
- **Interactive Detail Modals:** View comprehensive eligibility criteria, deadlines, and grant amounts.
- **Quick Apply Portal:** Built-in application form allowing students to submit their details directly.
- **Unified Application Tracker:** Real-time tracking dashboard to manage bookmarked and submitted applications.

## 🛠️ Tech Stack
- **HTML5 & Modern CSS**
- **Tailwind CSS (CDN)** for rapid, responsive UI styling
- **JavaScript (ES6+)** for DOM manipulation and dynamic state management
- **Lucide Icons** for clean, modern iconography

## 💻 Local Setup
1. Clone the repository or download the source code.
2. Open the project folder in **VS Code**.
3. Run using the **Live Server** extension.
